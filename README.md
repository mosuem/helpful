# helpful

A lightweight Dart utility library providing helpful extensions and helpers.

## Features

- Simple and clean helper utilities for Dart applications.
- Zero external runtime dependencies.

## Getting started

Add `helpful` to your `pubspec.yaml`:

```yaml
dependencies:
  helpful: ^0.1.0
```

## Usage

```dart
import 'package:helpful/helpful.dart';

void main() {
  final result = calculate();
  print('Result: $result');
}
```
